# ADR-0036：全局提案与有界详细分类

状态：S3 实施；与 S1 动态暂存独立组合。

## 决定

全局阶段保留完整来源清单和完整工作区目录。每份源码的有界摘要仅产生 preliminary 提案；详细阶段使用带行号/块标记/覆盖统计的源码，允许修订全局提案。主分类、算法族、技巧、变体、语言或复杂度冲突均记录来源与版本并标记 needsReview；不让 1200 字符摘要覆盖详细结果。全局组内分歧不自动否决全部响应，也不自动统一。

详细请求有界分批，所有 ID 必须唯一并完整覆盖；未知类别 ID、来源 ID、遗漏和取消继续失败关闭。跨批次以 sourceId 关联版本，最后统一复核。任何模型建议都不直接写源码或元数据。

## 组合契约

S1 可调用 classify / classifyBatch，保留返回的 reviewReasons、sourceEvidence、sourceCoverage 和 proposalHistory；不可把元数据完成当成分类确认。来源选择、暂存和最终 apply 由 S1 持有。
