# ADR-0026：当前工作区是业务数据的唯一可见边界

> 旧备份兼容读取部分已由 ADR-0031 取代；当前应用只接受唯一工作区与单文件 v2 格式。

- 状态：已接受
- 日期：2026-07-24

## 背景

应用允许用户登记多个模板工作区，但现有实现的边界不一致：模板和文件计划大多按
活动工作区查询，题目表没有 `workspace_id`，题目列表、搜索和部分统计会聚合整个
数据库；数据健康、失效执行记录和 v2 便携备份也会遍历全部已知工作区。用户无法从
页面判断一次查看、删除、导出或恢复究竟影响当前工作区还是其他工作区。

产品现采用统一规则：用户当前选择的工作区是模板、题目、关联、AI 文件管理、数据
状态、备份与恢复的唯一业务数据边界。切换工作区只切换可见域，不删除其他工作区
的数据；切回原工作区后仍可访问原数据。

## 决策

1. 给 `problems` 增加必填的 `workspace_id` 领域归属。既有 V2 题目通过 migration
   归属到升级时的活动工作区；若活动工作区缺失，则使用数据库中的首个工作区。升级
   不删除数据库。
2. 题目创建、AI 草稿确认、列表、分页、详情、图片、编辑、删除和模板关联全部由 Main
   从活动工作区解析归属。请求中的裸题目 ID 或模板 ID不能越过当前工作区。
3. 模板、题目、首页最近项、全局搜索、关联选择、总体文件 AI、计划历史、执行/撤销
   和失效执行清理只读取当前工作区。Renderer 不传入可伪造的工作区 ID。
4. 数据状态只统计和检查当前工作区的题目图片、文件计划及受管撤销备份。数据库自身
   的 `quick_check` / 外键检查仍是连接级安全检查，但不得把其他工作区的业务记录
   数量或文件问题展示为当前工作区问题。
5. 新导出的 v2 `.awb-backup` 只包含当前工作区的一条 workspace 记录及其模板、
   元数据、题目、图片、关联、文件计划、执行记录、受管撤销备份和完整模板源码。
   Provider 配置、任务路由、密钥、其他工作区及无归属的批量临时备份不进入工作区
   备份。
6. 恢复是“替换当前工作区”，不是合并，也不是替换整个应用。其他工作区和全局
   Provider 配置保持不变。恢复包必须只描述一个工作区；旧的多工作区 v2 包可继续
   验证，但在当前边界下拒绝恢复并给出可操作提示。
7. 恢复包的源工作区 ID/名称仅用于溯源，不拥有恢复目标权限。无论来源工作区是否仍
   已登记，恢复目标始终是执行时的活动工作区。Main 在临时包副本中为目标重映射全局
   主键和文件目录引用，因此来源身份或 ID 碰撞不得成为要求切换工作区的理由。
8. 应用级设置（语言、主题、窗口布局）和 AI Provider/任务路由仍是全局配置，不在
   工作区页面间复制；它们也不属于当前工作区便携备份。

## 数据保护与兼容

- migration 只为既有题目补充归属，不移动模板源码或题目图片。
- 任一工作区的普通 CRUD 都在数据库条件中同时校验活动工作区与记录 ID。
- 工作区备份导出先生成过滤后的 SQLite 快照，再根据该快照精确复制文件；禁止先复制
  整个共享目录后只在 manifest 中声称已过滤。
- 恢复前创建当前工作区预备份。数据库替换与共享文件目录变更必须具有失败补偿；
  其他工作区的文件目录和数据库行不得参与替换。
- v2 恢复固定创建全新模板根；当前目标保留自己的 ID/名称，模板相对路径、元数据、
  题目内容、图片和关系等价复制。恢复后修改目标文件或数据不得影响来源工作区。
- v1 目录备份和旧多工作区 v2 包不再拥有整库覆盖入口。兼容读取不能突破当前工作区
  边界。

## 验收

- 两个工作区分别创建模板、题目、图片、关联和文件计划；切换后列表、详情、搜索、
  首页、AI 管理、历史、失效记录和数据状态均只显示当前工作区。
- 使用其他工作区的题目、图片、模板或执行 ID 调用 IPC 时返回不存在/不可用，不修改
  数据或文件。
- 当前工作区备份 manifest 的 `workspaces` 长度恒为 1，SQLite 快照和归档文件均
  不含其他工作区或 Provider 配置。
- 从 A 导出后允许在任意当前工作区 B 恢复，即使 A 仍已登记。恢复后 B 保留 ID/名称，
  内容与备份等价且内部 ID 安全重映射；A 的数据库行、模板源码、题目图片、计划备份
  和 Provider 配置哈希/计数不变，随后修改 B 也不影响 A。
- 全新 userData、既有 V2 migration、空白当前工作区、亮暗主题和常用窗口尺寸通过
  自动化及截图验收。
