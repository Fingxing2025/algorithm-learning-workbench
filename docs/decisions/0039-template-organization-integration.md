# ADR-0039：模板分类整理的统一开发与集成边界

日期：2026-09-14。状态：接受执行，具体数据契约由对应实现 ADR 补充。

用户已授权执行分类准确性与文件整理规划，并将未来开发集中到 `codex/template-organization-next`。旧分支保留为来源，不继续形成互相独立的产品线。

以动态暂存作为导入执行骨架，规范 categoryId、可验证源码证据与显式复核作为共同分类契约。既有文件整理通过现有计划/预览/确认/备份执行入口，禁止从模型结果直接写入正式工作区。

全局事实只表达有版本的候选结论，详细证据可以修订；分类草稿不能冒充用户确认事实。阶段状态、分类状态与最终应用状态分别表示。文件系统和 SQLite 的一致性依赖备份、操作日志及恢复协议，不能声称跨两者存在单一数据库事务。

独立任务通过隔离工作树实现，整合负责人唯一写入长期分支。迁移和 ADR 编号在集成前去重，保留已发行 V2 数据。分类指标与软件功能测试分别验收，真实模型评测未运行时明确记为未验证。

详见 `docs/TEMPLATE_ORGANIZATION_EXECUTION_PLAN.md`。
