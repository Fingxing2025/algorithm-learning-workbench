# ADR-0034：规范模板分类与安全路径映射

状态：S3 实施。

## 背景与决定

采用 taxonomy v2 白名单保存稳定 categoryId、别名、具体叶节点和待审回退；保留现有 ADR-0035 核心元数据。导入与文件 AI 计划共用 taxonomy，本地生成/校验路径，未知 ID 失败关闭。同义归一化只移除排版分隔符，保留 C++、C# 等有语义的符号。

一个模板只有一个主分类，语言、技巧和场景进入多 tags/variant；复合/未知/泛化分类和新增分类提案均待审，模型不能修改规范分类表。名称或注释匹配只提供线索，不能作为已验证源码事实。

跨文件一致性按归一化算法族分组并按来源身份回写。组间不共享替换键；组内有分歧时保留各自提案并要求复核，不按自报最高置信度投票。

## 后果与验收

不移动真实文件、不更改既有模板元数据。原有预览、逐项确认和事务回滚边界保留。用跨族共享 ID、真实源码、未知 ID 和路径攻击回归验证，别名 fixture 只证明映射契约，不代表模型准确率。
