# ADR-0037：源码证据、本地核验与用户复核锁

状态：S3 实施。

## 决定

模型返回结构化 sourceEvidence（startLine/endLine/quote/claim）。Main 验证引用的原始源码行和实际发送覆盖范围；不匹配、未发送、缺失证据都进入待审。存在源码文本不等于算法语义已证明；UI 明示这是引用核验。

长文件按函数/花括号块边界优先、按有界行块退化，采样覆盖全文位置；每个片段保留原行号、是否完整块，显式返回总行数/覆盖区间/遗漏行数。部分覆盖一律待审，不将头尾截断伪装完整，不新增解析器重依赖。

低置信度、相近候选、未知算法族、复合算法、泛化节点、证据不足、新类别提案、阶段冲突和组内冲突均需用户确认。主分类与多标签/variant 分开显示。

导入草稿的确认锁绑定该项当前源码与分类结果；用户确认后再次批量 AI 处理跳过锁定项，编辑路径或替换来源解除锁，显式解锁后方可重新建议。最终入库仍走既有用户确认。此锁只在当前草稿会话有效；跨重启持久化分类锁应由后续 0010 migration 独立实现，不能复用 S1 的 0009，也不能将当前锁宣称为永久锁。

## 验收

独立真实源码 fixture 验证中段算法、引用伪造、越界、被省略块、全局/详细冲突、跨族共享分类、保留 C++ 符号以及 UI 复核锁。定向 Vitest、TypeScript、lint 和真实 Electron 截图；不报告真实模型准确率。
