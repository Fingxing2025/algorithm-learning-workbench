# 用户指南

## 从零开始

1. 启动“算法学习工作台”。首次启动不会读取旧项目、预置模板或开发者个人数据。
2. 选择“创建空白工作区”，指定一个新目录；也可以选择已有源码目录，首次扫描只读，不会自动移动或改名。
3. 在模板库选择“新建模板”，粘贴源码或上传源码文件。没有配置 AI 时也能手动填写路径与算法卡片。
4. 在“题目”中新建题目卡片，填写题面、状态和备注，并手动关联一个或多个模板。
5. 如需 AI，在“AI 管理 → Provider 配置”添加服务并选择任务路由。

## 模板与题目

- 模板源码始终保存在你选择的工作区中；SQLite 只保存索引、元数据和关联。
- 模板树会在显示层折叠单子目录，不会因此移动真实文件。
- 题目与模板是多对多关系；解除关系不会删除题目或模板。
- 题目图片存放于应用数据目录，不会自动上传；只有执行题目 AI 分析时才发送给当前视觉任务 Provider。

## AI Provider 与隐私

- Provider 由你自行配置，包括 Base URL、协议、模型、能力、超时和 API Key。
- “DeepSeek”预设会填写官方兼容端点和当前推荐的 `deepseek-v4-flash`；可按需改为 `deepseek-v4-pro`。
- “阿里云百炼”预设会填写 `qwen-plus` 并显示北京兼容端点模板；你需要把其中的 `<WorkspaceId>` 替换为自己的百炼工作空间 ID，其他地域使用控制台对应端点。
- API Key 使用操作系统安全存储加密；界面、SQLite 和日志不会回显明文。Linux 系统安全存储不安全或不可用时，应用会拒绝保存密钥。
- 题目分析会发送你输入的题面和选择的图片；模板分类会发送当前源码；总体文件 AI 管理会发送路径、结构化元数据和总量受限的源码片段。
- 使用 AI 前请确认界面显示的 Provider 和模型。自定义 Provider 由你信任；应用无法保证第三方服务如何保留或使用数据。
- 没有 Provider 或断网时，模板浏览、题目管理和手动关联仍可使用。

## AI 草稿与文件管理

- 题目 AI 分析只生成可编辑草稿。取消不会创建题目、图片或关联；确认后才入库。
- 文件 AI 管理先执行只读审计，再生成受限计划。AI 不能直接执行命令、覆盖源码或任意删除文件。
- 每项移动、删除重复文件或元数据更新都可以单独取消；最终执行前会再次显示 Diff 和确认。
- 执行文件计划前会在应用数据目录创建备份。成功撤销后对应备份立即清理；未撤销的执行仍保留备份，以保证恢复能力。
- 如果文件在计划执行后被外部程序修改，撤销会停止并提示冲突，不会覆盖后续用户数据。

## 数据位置与备份

- 模板源码：你选择的模板工作区。
- SQLite、题目图片、加密密钥文件和撤销备份：Electron 的系统应用数据目录。
- macOS 通常位于 `~/Library/Application Support/算法学习工作台/`；Windows 通常位于 `%APPDATA%/算法学习工作台/`。实际位置由 Electron 与操作系统决定。
- 建议同时备份模板工作区和应用数据目录。不要只备份数据库而忽略模板源码，也不要只备份源码而忽略题目、关系和笔记。
- V2 不支持从旧版项目迁移；版本升级仅通过 V2 自身的数据库 migration 原位保护现有 V2 数据。

## 当前发布限制

- 0.1.1 的 macOS 开发产物尚未 Developer ID 签名或 notarize，系统可能阻止或警告；不要把它当作公开正式发行版。
- Windows NSIS 已配置 CI 构建，但尚未在真实 Windows 主机完成安装、卸载和文件权限验收。
- 正式公开发布前需完成代码签名、公证、Windows 实机验证和可信下载渠道。
