## 2026-07-18 Session D：窗口适配与可访问交互

本轮没有重做视觉系统，而是从真实 Electron 入口审计 1440×900、1280×720、1024×640、200% 缩放、亮暗主题、键盘焦点和语义树后，收紧已有工作台的布局契约。

### 可调整工作台

- 只有真正具有列表/树与详情关系的页面使用分隔条：应用导航、模板库、题目、Provider 设置。
- 分隔条使用 `role="separator"`、垂直方向、当前/最小/最大值和中文值描述；鼠标拖动与方向键均使用同一安全边界。
- 键盘契约：左右方向键每次 8 px，`Shift` + 方向键每次 32 px，Home/End 到边界，Enter/Space 与双击恢复页面默认值。
- 导航、主面板和详情面板均保留安全最小尺寸；面板包裹层继承容器高度并裁剪，模板虚拟树、题目列表和计划历史只在各自区域滚动。
- Renderer `localStorage` 使用 `ui:layout:v1:` 前缀和稳定 key：`app-navigation`、`template-library`、`problem-workspace`、`ai-provider-workspace`。只记录数值宽度，不记录用户绝对路径，也不进入备份。
- 全局“重置布局”只清除布局偏好；无效、过期或越界值自动回退，新用户直接使用默认值。

### 紧凑窗口与 200% 缩放

- Electron 真实最小窗口为 1024×640，不再用 680 px 最小高度伪造通过。
- 有效视口宽度不超过 820 px 时，导航缩为 72 px 图标栏；工作台、模板库、题目、AI 管理、数据管理和 AI 设置六个入口继续存在并具有 accessible name。
- 紧凑页头允许标题、说明和操作换行；长工作区名、长相对路径和长标题使用 `min-width: 0`、安全截断或 `overflow-wrap`，不能挤掉关闭、错误或主操作按钮。
- 首页窄视口隐藏重复的知识图装饰和营销 chip，压缩 Hero 与摘要卡间距；“浏览题目”“浏览模板库”“新建模板”三个核心操作仍保留。
- 徽标允许多标签换行，但语言徽标使用 `shrink-0`，避免 `C++` 被压成逐字竖排。

### 焦点、播报与动效

- 所有可操作控件使用可见 `focus-visible` 环；分隔条焦点不能只靠颜色变化，其把手宽度和背景同时变化。
- 对话框打开后焦点进入有效首项；Escape、取消和右上角关闭均零副作用并回到触发器。延迟焦点恢复只在当前焦点为空闲时发生，不能抢走用户刚移动到的新控件。
- 页面切换、成功和普通进度使用 polite `status`；错误使用 assertive `alert`。播报只包含任务结果和下一步，不复述题面、源码、Provider 响应或文件正文。
- 模板树支持方向键、Home/End、Enter/Space 与父子导航；文件计划历史支持方向键/Home/End 和 Enter/Space 激活。
- `prefers-reduced-motion: reduce` 下所有 CSS 过渡/动画降至 0.01ms，Motion 不再应用非必要的 hover 位移或缩放；功能反馈仍由文字、图标和状态语义表达。

## 2026-07-15 精致度研究与第二轮优化

本轮对照了三类真实参考，而不是直接复制一套通用后台模板：

- [Linear UI patterns](https://www.saasui.design/application/linear)：借鉴安静内容面、紧凑侧栏、细边框和只在当前焦点处使用强调色。
- [Raycast](https://www.raycast.com/)：借鉴深色表面的层次、局部色光、键盘优先提示和高对比品牌时刻；强色光不进入长文本主体。
- [shadcn/ui Blocks](https://ui.shadcn.com/blocks)：借鉴可访问的侧栏、快捷键提示、表单状态和桌面/平板预览方法，不照搬其通用数据仪表盘结构。

结合当前产品，本轮确定：

1. 首页 Hero 右侧不再只放装饰圆环，加入由真实模板数、关系数和题目数驱动的知识脉络概览。
2. 侧栏展示 `Cmd/Ctrl + 1–4` 导航提示，并增加搜索和新建模板快捷操作坞；快捷键不会在输入框中抢占输入。
3. 玻璃工具栏增加克制的高光边缘；内容卡和列表行使用更细的边框、阴影和方向反馈。
4. 所有新增循环动效都限制在小面积状态点，并继续服从 `prefers-reduced-motion`。

精致度的后续判断标准不是“颜色是否更多”，而是用户能否更快区分应用框架、当前焦点、可操作元素和数据关系。

## 目标

界面需要比单一紫灰工作台更有活力，但不能退化成渐变、玻璃和动画的堆叠。视觉层级继续服务模板、题目、AI 计划与本地状态，而不是制造与功能无关的装饰噪音。

本轮基准来自用户提供的亮色/暗色 Demo，并在 2026-07-15 参考以下公开案例与指南：

- [Raycast Design System Analysis](https://getdesign.md/raycast/design-md)：采用近黑表面阶梯、细边框、少量高饱和分类色和命令式工作台布局。
- [Apple Human Interface Guidelines — Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：玻璃材质用于导航、控制与瞬时浮层；内容层使用更稳定的标准材质，优先保证层级与可读性。
- [Aura — Futuristic Glassmorphism Dashboard](https://www.aura.build/templates/futuristic-glassmorph-85)：用于观察彩色环境光、玻璃控件和模块化卡片的组合方式，不直接复制模板。

## 色彩语义

- 紫蓝：品牌、工作台、主要操作、模板元数据。
- 青色：模板库、搜索、信息与本地连接感。
- 青绿：题目关联成功、工作区可用、确认状态。
- 珊瑚：题目内容、图片与需要注意的编辑区域。
- 琥珀：AI 管理、待确认计划、文件整理风险。

亮色主题通过柔和环境光和浅色语义底色增加层次；暗色主题通过近黑表面阶梯承载内容，高饱和颜色只用于导航状态、图标、边缘和关键焦点区。

## 材质规则

- 顶栏、侧栏、搜索框、通知和对话框使用模糊、透明度、细边框与饱和度增强形成的玻璃材质。
- 数据卡、代码区、题目详情和表单保持较高不透明度，避免长文本漂浮在复杂背景上。
- 每个页面最多一个大面积品牌渐变焦点区；其他区域只使用低透明环境光或单边色彩提示。
- 亮暗主题都必须保持清晰的边框、文字层级和焦点环。

## 动效规则

- 页面切换：约 240ms 的淡入与轻微纵向位移。
- 按钮与卡片：150–240ms 的轻微抬升、饱和度和阴影变化。
- 品牌标识：低频高光掠过；背景环境光以 18s 周期缓慢漂移。
- 首页状态卡：首次进入时按 70ms 错峰出现。
- 所有装饰动画在 `prefers-reduced-motion: reduce` 下缩短至近乎静止。

## 组件落地

- 应用外壳：玻璃顶栏与侧栏，四色导航语义，动态品牌图标。
- 工作台：首页使用紫蓝到青色的焦点区、三张语义概览卡和带色彩边缘的内容卡。
- 模板库：青色页头标识，模板选择继续使用紫色以维持品牌一致性。
- 题目：青绿与珊瑚共同表达“已关联”和“题目内容”。
- AI 管理：琥珀承担待确认和风险语义，紫蓝只用于模型与 Provider 配置。

## 禁止项

- 不在每张内容卡上叠加玻璃或强渐变。
- 不用持续缩放、弹跳或快速闪烁吸引注意。
- 不用颜色替代文字标签、状态描述或错误说明。
- 不牺牲代码阅读、题目长文本和表单输入的对比度。
