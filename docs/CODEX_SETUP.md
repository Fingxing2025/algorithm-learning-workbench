## 配置层级

- `AGENTS.md`：产品范围、架构、安全、UI 和验收要求，是仓库长期规则。
- `.codex/config.toml`：Codex 的项目级安全与推理默认值。
- `docs/`：产品、架构和质量事实；发生决策变化时必须同步更新。
- 当前任务提示：只放本轮目标、范围和临时偏好，不重复粘贴整套项目背景。

## 已安装的官方 Skills

- `playwright`：浏览器与 Electron 端到端回归测试。
- `screenshot`：关键页面视觉检查与截图基线。
- `security-best-practices`：Electron、IPC、密钥和网络实现安全审查。
- `security-threat-model`：在实现文件 AI 管理和多 Provider 前建立威胁模型。

这些 Skill 从安装后的下一轮任务开始可用。Codex 当前环境还内置浏览器控制、图像生成、Skill 创建和官方文档能力。

## 推荐任务拆分

每轮让 Codex完成一个可验证纵向切片，例如：

1. “根据规格初始化 Electron/React 工程，先做到安全窗口启动和测试通过。”
2. “建立设计 token 和三个基础工作台组件，使用截图验收亮暗主题。”
3. “实现首次启动、空白工作区、只读模板扫描、展示路径折叠和树形浏览。”
4. “实现题目卡片与模板关联的数据模型、schema migration 和界面。”

避免把“完成全部 V2”作为一个不可审查的超大任务。
